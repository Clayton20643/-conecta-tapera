# CONECTA TAPERA

**Sua cidade conectada. Sua comunidade mais forte.**

Plataforma regional para aproximar moradores, comerciantes, empresas, prestadores de serviços e organizações sociais de São José da Tapera–AL e municípios vizinhos.

## Módulos planejados
- Diretório de empresas, comércios e profissionais.
- Catálogo de produtos e serviços.
- Oportunidades de emprego.
- Notícias, comunicados e agenda de eventos.
- Informações úteis da comunidade.
- Painel administrativo e moderação.

## Tecnologia inicial
React, Vite, JavaScript e CSS responsivo. A interface desta primeira etapa utiliza conteúdo demonstrativo no próprio frontend.

## Executar localmente
```bash
npm install
npm run dev
```

## Situação da implementação
A base visual responsiva está sendo construída. Autenticação, banco de dados, API, persistência, painel administrativo funcional e aplicativo Android ainda serão etapas posteriores. Não use esta versão para coletar dados pessoais reais.

Consulte [docs/architecture.md](docs/architecture.md) para a arquitetura e o roadmap.
